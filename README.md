# Protfolio_A26

Vue portfolio project deployed with GitHub Pages from GitHub Actions.

## Deploy to GitHub Pages

1. In GitHub, open **Settings → Pages** and set **Source** to **GitHub Actions**.
2. Push to `main` (or run the workflow manually from **Actions → Deploy portfolio to GitHub Pages**).
3. The site is published at:
   - https://shihab173066.github.io/Protfolio_A26/

The workflow builds the Vite app from `shihab-portfolio/` and deploys the generated `dist/` artifact.
